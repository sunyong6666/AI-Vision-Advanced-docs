# FAQ
## **Issue: Lag during Use**
+ **Check the communication protocol being used**:
    - If using **SPIKE**, it is recommended to use the **SPIKE controller** for power supply.
    - If using **IIC** or **UART**, it is recommended to use **USB** or **Grove interface** for power supply.

## Issue:  Unable to switch port protocol 
+ Check the current port protocol in use.
    -  If the module is currently set to SPIKE and needs to be switched to IIC or UART, press and hold the dial while the module is powered on to switch the protocol.
